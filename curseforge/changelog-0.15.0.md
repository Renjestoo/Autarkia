## Autarkia 0.15.0

- **Developer test code removed.** The mod no longer contains its milestone self tests, the showcase scenes and the effect checks. The commands `/autarkia test`, `/autarkia showcase` and `/autarkia fx` are gone, and so is the scripted-scene reader. The admin commands `/autarkia colony`, `worker`, `nanite`, `restore`, `pattern` and `profile` stay.
