# A Colony That Learns

The <ItemLink id="autarkia:core_upgrade_t3" /> makes your colony Tier 3. The domain grows to 65 x 65 blocks and the colony gets electric workers.

## Failure memory

The colony remembers each failure: a snapped cable, a fuse trip, a rack collapse, a boiler burst, a destroyed machine. A memory loses half its weight in 7 days. While the memory is strong, the colony prefers the project that stops the same failure.

Examples:

- A cable snapped. A Lineman puts a <ItemLink id="autarkia:fuse_box" /> on that line.
- A wood rack collapsed. The workers prop the row with <ItemLink id="autarkia:prop_beam" /> blocks and replace it with steel racks.

## Repair and copies

A watched Pattern is a build that the colony protects. When a creeper, a mob or a stranger breaks it, Builder Drones put the same blocks back, bottom row first. Blocks that you or a trusted player break stay removed.

When the machines of a LINE Pattern have a long queue, the colony builds a copy of the line. It splits the feed belt with a belt splitter and connects the copy to power.

## Domain and ore

- <ItemLink id="autarkia:domain_beacon" /> adds a 33 x 33 square to the domain. A Tier 3 colony can have 2 beacons.
- <ItemLink id="autarkia:survey_lens" /> shows the ore deposits within 64 blocks through the ground.
