# Electric Workers

Tier 3 workers use an FE battery. They charge at a <ItemLink id="autarkia:recharge_dock" />, which also repairs them.
Make them in the worker assembler.

| Worker | Frame | Work |
|---|---|---|
| Builder Drone | <ItemLink id="autarkia:drone_frame" /> | Flies. Builds, cuts and repairs any block, strings cable. |
| Loader | crab frame | Carries warehouse crates between racks and ledger terminals. |
| Lineman | walker frame | Climbs poles. Strings and cuts spans, places fuse boxes and poles. |

## Upgrades

Right-click a worker with an upgrade. Each worker has 2 slots.

- <ItemLink id="autarkia:worker_upgrade_speed" />: +20% speed.
- <ItemLink id="autarkia:worker_upgrade_cargo" />: +1 carry slot. A Loader moves 2 crates per trip.
- <ItemLink id="autarkia:worker_upgrade_armor" />: +6 armor, +25% health.
- <ItemLink id="autarkia:worker_upgrade_range" />: +2 reach.
