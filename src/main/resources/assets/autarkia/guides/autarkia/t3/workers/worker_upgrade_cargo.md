# Cargo Upgrade

<ItemImage id="autarkia:worker_upgrade_cargo" scale="2" />

The cargo upgrade gives a worker one more carry slot. On a Loader it adds 9 pallet slots, and the Loader moves 2 crates per warehouse trip.

## Get it

<RecipeFor id="autarkia:worker_upgrade_cargo" />

## Use it

1. Hold the upgrade.
2. Use it on a worker of your colony. The upgrade is used up.
3. The action bar shows "Installed: Cargo Upgrade".

Each worker has 2 upgrade slots. Two cargo upgrades give 2 more slots. To take all upgrades out, sneak and use a <ItemLink id="autarkia:wrench" /> on the worker.

## Numbers

| Property | Value |
|---|---|
| Carry slots | +1 per upgrade |
| Loader | +9 pallet slots per upgrade, 2 crates per trip |
| Move drain | +5% per upgrade |
| Slots per worker | 2 |

## Problems

- "Both upgrade slots are full": take the upgrades out with a sneaking wrench first.
- "Only the owner or a trusted player can upgrade this worker": the worker belongs to another player's colony.
