# Range Upgrade

<ItemImage id="autarkia:worker_upgrade_range" scale="2" />

The range upgrade lets a worker work from 2 blocks farther away. At Tier 4 it also extends the scan of the Surveyor and the shot range of the Sentinel.

## Get it

<RecipeFor id="autarkia:worker_upgrade_range" />

## Use it

1. Hold the upgrade.
2. Use it on a worker of your colony. The upgrade is used up.
3. The action bar shows "Installed: Range Upgrade".

Each worker has 2 upgrade slots. To take all upgrades out, sneak and use a <ItemLink id="autarkia:wrench" /> on the worker.

## Numbers

| Property | Value |
|---|---|
| Reach | +2 blocks per upgrade |
| Surveyor scan radius | +16 blocks per upgrade |
| Sentinel shot range | +4 blocks per upgrade |
| Slots per worker | 2 |

## Problems

- "Both upgrade slots are full": take the upgrades out with a sneaking wrench first.
- "Only the owner or a trusted player can upgrade this worker": the worker belongs to another player's colony.
