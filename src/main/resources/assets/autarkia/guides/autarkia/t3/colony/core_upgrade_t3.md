# Core Upgrade T3

<ItemImage id="autarkia:core_upgrade_t3" scale="2" />

The Core Upgrade T3 raises a Tier 2 colony to Tier 3. The domain grows, the colony can have more workers, and it gets electric workers, the warehouse and failure memory.

## Get it

| Input | Machine | Time | Energy | Output |
|---|---|---|---|---|
| 4 <ItemLink id="autarkia:basic_circuit" />, 2 <ItemLink id="autarkia:servo" />, 4 <ItemLink id="autarkia:steel_plate" />, 1 <ItemLink id="autarkia:battery_bank" /> | <ItemLink id="autarkia:fabricator" /> | 400 ticks (20 s) | 160 FE/t | 1 Core Upgrade T3 |

You can make the fabricator, the circuits and the battery bank while your colony is still Tier 2.

## Use it

1. Hold the upgrade.
2. Use it on your Tier 2 Colony Core. You must be the owner or a trusted player.
3. The Core upgrades for 5 seconds. The upgrade item is used up.
4. The colony is now Tier 3.

## What Tier 3 gives

| Property | Tier 2 | Tier 3 |
|---|---|---|
| Domain half-size | 24 | 32 (65 x 65 blocks) |
| Worker cap | 8 | 14 |
| Active projects at one time | 2 | 3 |
| Pattern library | 4 | 12 |
| Largest Pattern per axis | 16 | 24 |
| Domain beacons | 0 | 2 |

New at Tier 3:

- Builder Drones, Loaders and Linemen in the <ItemLink id="autarkia:worker_assembler" />.
- The warehouse with the <ItemLink id="autarkia:warehouse_controller" /> and Loaders.
- Failure memory: the colony remembers failures and builds projects that stop them.
- New colony projects: Fuse Box, Rack Upgrade, Second Line, Pattern Repair, Recharge Dock, Turbine Hall and Battery Row.
- <ItemLink id="autarkia:domain_beacon" /> blocks that make the domain larger.

## Problems

- "This upgrade needs a T2 Core (this one is T1)": use the <ItemLink id="autarkia:core_upgrade_t2" /> first.
- "The Core must be active": the Core is not active yet.
- "The Core is already upgrading": wait 5 seconds.
- "Only the owner or trusted players can do this": ask the owner of the colony.
