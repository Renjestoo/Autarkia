# Core Upgrade T4

<ItemImage id="autarkia:core_upgrade_t4" scale="2" />

The Core Upgrade T4 raises a Tier 3 Colony Core to Tier 4. The colony gets a bigger domain, more workers, outposts,
HV lines, cable cars and the Tier 4 workers.

## Get it

| Inputs | Machine | Time | Output |
|---|---|---|---|
| 4 <ItemLink id="autarkia:advanced_circuit" />, 8 <ItemLink id="autarkia:vantite_steel_ingot" />, 4 <ItemLink id="autarkia:servo" /> | <ItemLink id="autarkia:fabricator" /> | 200 ticks, 160 FE/t (32,000 FE) | 1 Core Upgrade T4 |

Set the fabricator target to the Core Upgrade T4. The fabricator then pulls the parts from its buffer.

## Use it

1. Hold the upgrade. You must be the owner of the colony or a trusted player.
2. Use it on your active Tier 3 Colony Core.
3. The Core plays its upgrade for 100 ticks. Then the colony is Tier 4.

## Numbers

| Tier 4 value | Amount |
|---|---|
| Domain half-size | 48 blocks |
| Worker cap | 20 |
| Active projects | 4 |
| Daily budget | 1,000 points |
| Pattern library | 24 Patterns, capture up to 32 blocks on each axis |
| Domain beacons | 3, half-size 16 each |
| Outposts | 6, half-size 24 each |
| Worker cap of each outpost core | 6 |
| Leveling edits for each project | 512 |
| Largest height difference of a site | 5 blocks |

New at Tier 4: the Surveyor, the Cable-Layer Drone and the Sentinel in the worker assembler, and the projects
Outpost, HV Link, Cable Car, Sentinel Post, Wind Tower and Hydro Turbine.

## Problems

- "The Core must be active": the Core is not active. Wait until it is.
- "Only the owner or trusted players can do this": ask the owner to trust you.
- "The Core is already upgrading": wait for the current upgrade to end.
- "This upgrade needs a T3 Core (this one is T2)": use the right upgrade for the tier of the Core.
