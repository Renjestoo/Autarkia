# Block of Vantite Steel

<ItemImage id="autarkia:vantite_steel_block" scale="2" />

A storage block for 9 vantite steel ingots. Some big machines use the block itself.

## Get it

<RecipeFor id="autarkia:vantite_steel_block" />

## Use it

1. Craft 9 <ItemLink id="autarkia:vantite_steel_ingot" /> into 1 block.
2. Put the block in a crafting grid to get the 9 ingots back.
3. Mine the placed block with a diamond level pickaxe. The steel pickaxe counts.

## Numbers

| Property | Value |
|---|---|
| Content | 9 vantite steel ingots |
| Hardness | 7.0 |
| Blast resistance | 12.0 |
| Tool | Diamond level pickaxe |
| Drop | Itself |
