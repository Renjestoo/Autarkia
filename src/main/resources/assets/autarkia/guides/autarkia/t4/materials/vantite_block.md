# Block of Vantite

<ItemImage id="autarkia:vantite_block" scale="2" />

A storage block for 9 vantite ingots.

## Get it

<RecipeFor id="autarkia:vantite_block" />

## Use it

1. Craft 9 <ItemLink id="autarkia:vantite_ingot" /> into 1 block.
2. Put the block in a crafting grid to get the 9 ingots back.
3. Mine the placed block with a diamond level pickaxe. The steel pickaxe counts.

## Numbers

| Property | Value |
|---|---|
| Content | 9 vantite ingots |
| Hardness | 6.0 |
| Blast resistance | 9.0 |
| Tool | Diamond level pickaxe |
| Drop | Itself |
