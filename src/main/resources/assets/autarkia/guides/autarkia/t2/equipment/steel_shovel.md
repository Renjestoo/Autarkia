# Steel Shovel

<ItemImage id="autarkia:steel_shovel" scale="2" />

The steel shovel digs dirt, sand and gravel fast.

## Get it

<RecipeFor id="autarkia:steel_shovel" />

Make the steel ingots in the <ItemLink id="autarkia:blast_smelter" />.

## Use it

1. Hold the shovel.
2. Dig dirt, sand, gravel and snow.
3. Use it on a grass block to make a path.
4. Repair it with steel ingots in an anvil.
