# Block of Raw Zinc

<ItemImage id="autarkia:raw_zinc_block" scale="2" />

The block of raw zinc stores nine raw zinc in one block. Use it to save space in your storage.

## Get it

<RecipeFor id="autarkia:raw_zinc_block" />

## Use it

1. Craft nine <ItemLink id="autarkia:raw_zinc" /> into one block.
2. Place it, or keep it in a chest.
3. Craft the block back into nine raw zinc when you need them.

## Numbers

| Property | Value |
|---|---|
| Contents | 9 raw zinc |
| Hardness | 5 |
| Tool | Pickaxe, stone or better |
| Drop | Itself |
