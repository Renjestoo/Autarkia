# Block of Brass

<ItemImage id="autarkia:brass_block" scale="2" />

The block of brass stores nine brass ingots in one block. The lightning mast uses it as a part.

## Get it

<RecipeFor id="autarkia:brass_block" />

## Use it

1. Craft nine <ItemLink id="autarkia:brass_ingot" /> into one block.
2. Place it, or keep it in a chest.
3. Craft the block back into nine brass ingots when you need them.

## Numbers

| Property | Value |
|---|---|
| Contents | 9 brass ingots |
| Hardness | 5 |
| Tool | Pickaxe, stone or better |
| Drop | Itself |
