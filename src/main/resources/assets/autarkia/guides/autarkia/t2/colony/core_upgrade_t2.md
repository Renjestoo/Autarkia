# Core Upgrade T2

<ItemImage id="autarkia:core_upgrade_t2" scale="2" />

The Core Upgrade T2 raises a Tier 1 Colony Core to Tier 2. It is the last step of Tier 1 and the first step of Tier 2.
After the upgrade, the domain is bigger, the colony can have more workers and projects, and it learns the Tier 2
projects.

## Get it

<RecipeFor id="autarkia:core_upgrade_t2" />

## Use it

1. Make sure that the Core is active (fully grown).
2. Hold the upgrade and use it on the Colony Core. You must be the owner or a trusted player.
3. The upgrade is used up. Golden sparks circle up around the Core for 100 ticks (5 seconds).
4. After that, the colony is Tier 2.

## Numbers

| Property | Before | After |
|---|---|---|
| Tier | 1 | 2 |
| Domain | 33 x 33 blocks | 49 x 49 blocks |
| Worker cap | 4 | 8 |
| Active projects | 1 | 2 |
| Daily build budget | 64 points | 160 points |
| Pattern library | 0 | 4 Patterns |

| Property | Value |
|---|---|
| Upgrade time | 100 ticks |
| Works on | an active Tier 1 Core |

## Problems

- "The Core must be active": the Core still grows or is dormant. Wait until it is active.
- "Only the owner or trusted players can do this": ask the owner of the colony to trust you.
- "The Core is already upgrading": wait 5 seconds.
- "This upgrade needs a T1 Core (this one is T2)": the Core has this tier already. Use the next upgrade.
