# Block of Steel

<ItemImage id="autarkia:steel_block" scale="2" />

The block of steel stores nine steel ingots in one block. Many Tier 3 machines use it as a part.

## Get it

<RecipeFor id="autarkia:steel_block" />

## Use it

1. Craft nine <ItemLink id="autarkia:steel_ingot" /> into one block.
2. Place it, or keep it in a chest.
3. Craft the block back into nine steel ingots when you need them.

## Numbers

| Property | Value |
|---|---|
| Contents | 9 steel ingots |
| Hardness | 6 |
| Tool | Pickaxe, iron or better |
| Drop | Itself |
