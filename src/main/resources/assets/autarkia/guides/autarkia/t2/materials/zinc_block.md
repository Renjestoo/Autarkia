# Block of Zinc

<ItemImage id="autarkia:zinc_block" scale="2" />

The block of zinc stores nine zinc ingots in one block. The Tier 3 battery bank uses it as a part.

## Get it

<RecipeFor id="autarkia:zinc_block" />

## Use it

1. Craft nine <ItemLink id="autarkia:zinc_ingot" /> into one block.
2. Place it, or keep it in a chest.
3. Craft the block back into nine zinc ingots when you need them.

## Numbers

| Property | Value |
|---|---|
| Contents | 9 zinc ingots |
| Hardness | 4 |
| Tool | Pickaxe, stone or better |
| Drop | Itself |
