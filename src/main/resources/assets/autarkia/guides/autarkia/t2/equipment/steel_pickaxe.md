# Steel Pickaxe

<ItemImage id="autarkia:steel_pickaxe" scale="2" />

The steel pickaxe mines stone, ores and metal blocks. It mines every block that a diamond pickaxe mines.

## Get it

<RecipeFor id="autarkia:steel_pickaxe" />

Make the steel ingots in the <ItemLink id="autarkia:blast_smelter" />.

## Use it

1. Hold the pickaxe.
2. Mine stone, ore and metal blocks.
3. Repair it with steel ingots in an anvil.

## Numbers

| Property | Value |
|---|---|
| Mining speed | 7.5 |
| Mining level | Same as diamond |
| Attack damage | 4.5 |
| Attack speed | 1.2 |
| Durability | 1,200 uses |
| Durability per hit on a mob | 2 |
| Enchantability | 12 |
| Repair | Steel ingot |
