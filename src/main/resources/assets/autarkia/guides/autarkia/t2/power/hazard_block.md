# Hazard Block

<ItemImage id="autarkia:hazard_block" scale="2" />

The hazard block is a building block with yellow and black warning stripes. Use it to mark dangerous places: boilers
that can burst, hot wires, the area under a lightning mast or the edge of a catwalk.

## Get it

<RecipeFor id="autarkia:hazard_block" />

## Use it

1. Place it like a stone block.
2. Mine it with a pickaxe to get it back.

## Numbers

| Property | Value |
|---|---|
| Hardness | 2 |
| Blast resistance | 6 |
