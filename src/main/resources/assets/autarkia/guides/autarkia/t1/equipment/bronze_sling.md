# Bronze Sling

<ItemImage id="autarkia:bronze_sling" scale="2" />

The bronze sling is a Tier 1 ranged weapon. It throws cobblestone or nuggets. It needs no iron and no arrows, so you
can use it from the first day.

## Get it

<RecipeFor id="autarkia:bronze_sling" />

You need 3 sticks, 2 string and 1 leather. The recipe has no bronze in it.

## Use it

1. Put ammo in your inventory: cobblestone or any nugget, for example a <ItemLink id="autarkia:bronze_nugget" />.
2. To choose the ammo, put it in your off hand. The sling takes ammo from the off hand first, then from the
   inventory.
3. Hold the sling in your main hand.
4. Hold the use key for at least 5 ticks (0.25 seconds).
5. Release the use key. The sling throws 1 ammo item.
6. Hold the use key for 20 ticks (1 second) to throw at full speed.
7. To repair the sling, put it in an anvil with string.

## Numbers

| Property | Value |
|---|---|
| Durability | 250 shots |
| Damage, cobblestone | 3 |
| Damage, any nugget | 4 |
| Minimum charge | 5 ticks (0.25 seconds) |
| Full charge | 20 ticks (1 second) |
| Shot speed | 0.6 blocks per tick at minimum charge, up to 1.8 blocks per tick at full charge |
| Spread | 1.0 |
| Wear | 1 use for each shot |
| Cooldown | 10 ticks (0.5 seconds) after each shot |
| Repair item | String |

The shot is gone when it hits a block or a mob. You do not get the ammo back.

## Problems

- Nothing happens when you hold the use key: you have no cobblestone and no nuggets in your inventory. Get ammo.
- The sling does not throw when you release: you released before 5 ticks. Hold the use key longer.
