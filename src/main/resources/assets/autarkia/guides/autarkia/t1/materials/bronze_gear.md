# Bronze Gear

<ItemImage id="autarkia:bronze_gear" scale="2" />

The bronze gear is the main machine part of Tier 1. Generators, mills, nodes and workers need gears.

## Get it

<RecipeFor id="autarkia:bronze_gear" />

4 bronze ingots make 2 gears.

## Use it

Bronze gears go into:

| Group | Items |
|---|---|
| Power | <ItemLink id="autarkia:hand_crank" />, <ItemLink id="autarkia:rope_pulley" />, <ItemLink id="autarkia:treadwheel" />, <ItemLink id="autarkia:windmill" />, <ItemLink id="autarkia:stone_flywheel" /> |
| Processing | <ItemLink id="autarkia:stamp_mill" /> |
| Storage | <ItemLink id="autarkia:tally_board" /> |
| Colony | <ItemLink id="autarkia:core_seed" />, <ItemLink id="autarkia:core_upgrade_t2" /> |
| Workers | <ItemLink id="autarkia:walker_frame" />, <ItemLink id="autarkia:winding_post" />, <ItemLink id="autarkia:worker_assembler" /> |
| Tier 2 | Plate press, wire drawer |

Each Porter needs 4 bronze gears in the worker assembler.
