# Tin Ingot

<ItemImage id="autarkia:tin_ingot" scale="2" />

The tin ingot is the tin metal. Its main use is bronze: 3 copper ingots and 1 tin ingot make 4 bronze ingots in the
crucible.

## Get it

| Input | Machine | Time |
|---|---|---|
| <ItemLink id="autarkia:raw_tin" /> | Furnace / blast furnace | 200 / 100 ticks |
| <ItemLink id="autarkia:crushed_tin" /> | Furnace / blast furnace | 200 / 100 ticks |
| <ItemLink id="autarkia:tin_ore" /> or <ItemLink id="autarkia:deepslate_tin_ore" /> | Furnace / blast furnace | 200 / 100 ticks |
| 9 <ItemLink id="autarkia:tin_nugget" /> | Crafting table | - |
| 1 <ItemLink id="autarkia:tin_block" /> (gives 9) | Crafting table | - |

Each smelting gives 1 tin ingot and 0.7 experience. Later tiers have more ways to make tin ingots from washed ore and
concentrate.

<RecipeFor id="autarkia:tin_ingot" />

## Use it

1. Put 3 copper ingots and 1 tin ingot into a heated <ItemLink id="autarkia:crucible" />.
2. Take the 4 <ItemLink id="autarkia:bronze_ingot" />.
