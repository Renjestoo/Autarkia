# Bronze Pickaxe

<ItemImage id="autarkia:bronze_pickaxe" scale="2" />

The bronze pickaxe is the first Autarkia pickaxe. It mines all blocks that an iron pickaxe mines. It is faster than an
iron pickaxe and it has more uses.

## Get it

<RecipeFor id="autarkia:bronze_pickaxe" />

You need 3 <ItemLink id="autarkia:bronze_ingot" /> and 2 sticks.

## Use it

1. Hold the pickaxe in your main hand.
2. Mine stone, ores and other blocks that need a pickaxe.
3. To repair the pickaxe, put it in an anvil with a bronze ingot.

## Numbers

| Property | Value |
|---|---|
| Durability | 300 uses (iron pickaxe: 250) |
| Mining level | Iron. Blocks that need a diamond pickaxe, for example obsidian, drop nothing. |
| Mining speed | 6.5 (iron pickaxe: 6.0) |
| Attack damage | 4 |
| Attack speed | 1.2 |
| Wear | 1 use for each block, 2 uses for each hit on a mob |
| Enchantability | 16 |
| Repair item | Bronze Ingot |
