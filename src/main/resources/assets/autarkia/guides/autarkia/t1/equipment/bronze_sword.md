# Bronze Sword

<ItemImage id="autarkia:bronze_sword" scale="2" />

The bronze sword is the Tier 1 melee weapon. It does the same damage as an iron sword and it has more uses.

## Get it

<RecipeFor id="autarkia:bronze_sword" />

You need 2 <ItemLink id="autarkia:bronze_ingot" /> and 1 stick.

## Use it

1. Hold the sword in your main hand.
2. Hit a mob. Wait for the attack bar to fill before the next hit.
3. Stand on the ground, do not sprint, and hit with a full attack bar. This is a sweep attack. It also hits mobs
   near the target.
4. Use the sword to cut cobwebs fast.
5. To repair the sword, put it in an anvil with a bronze ingot.

## Numbers

| Property | Value |
|---|---|
| Durability | 300 uses (iron sword: 250) |
| Attack damage | 6 |
| Attack speed | 1.6 |
| Wear | 1 use for each hit on a mob, 2 uses for each block |
| Enchantability | 16 |
| Repair item | Bronze Ingot |
