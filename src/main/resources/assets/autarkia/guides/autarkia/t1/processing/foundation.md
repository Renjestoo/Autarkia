# Foundation

<ItemImage id="autarkia:foundation" scale="2" />

The foundation is a heavy building block. Heavy machines from Tier 2 work only when a foundation block is under each
of their bottom blocks. Make foundation blocks in Tier 1, so you are ready for Tier 2.

## Get it

<RecipesFor id="autarkia:foundation" />

The first recipe uses stone and clay balls and gives 4 blocks. The second recipe uses 4 slag and gives 2 blocks. Slag
comes from the blast smelter in Tier 2.

## Use it

1. Find the size of the heavy machine, for example 2 x 2 for the blast smelter.
2. Place foundation blocks in that area, one level below the machine.
3. Place the heavy machine on top. Each bottom block of the machine must stand on a foundation block.

## Numbers

| Property | Value |
|---|---|
| Blocks from the stone recipe | 4 |
| Blocks from the slag recipe | 2 |
| Mining tool | Pickaxe |

## Problems

- "Needs a foundation under every bottom block": Jade shows this on a heavy machine. One or more bottom blocks have no
  foundation below. Add the missing foundation blocks.
