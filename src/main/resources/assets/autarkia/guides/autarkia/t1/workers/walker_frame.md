# Walker Frame

<ItemImage id="autarkia:walker_frame" scale="2" />

The walker frame is the body of a two-legged worker. You need one frame for each Porter. The Lineman of Tier 3 also
uses a walker frame.

## Get it

<RecipeFor id="autarkia:walker_frame" />

You need 6 <ItemLink id="autarkia:bronze_ingot" /> and 2 <ItemLink id="autarkia:bronze_gear" />.

## Use it

1. Open a <ItemLink id="autarkia:worker_assembler" />.
2. Put the walker frame into the frame slot.
3. Put the parts of the Porter into the part slots.
4. Give the assembler power. The Porter walks out when it is done.

## Porter assembly

The worker assembler makes a Porter from these items. GuideME cannot show this recipe type, so it is shown here as a
table.

| Input | Count |
