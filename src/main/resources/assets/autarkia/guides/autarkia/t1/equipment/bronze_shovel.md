# Bronze Shovel

<ItemImage id="autarkia:bronze_shovel" scale="2" />

The bronze shovel digs dirt, sand and gravel. It is faster than an iron shovel and it has more uses.

## Get it

<RecipeFor id="autarkia:bronze_shovel" />

You need 1 <ItemLink id="autarkia:bronze_ingot" /> and 2 sticks.

## Use it

1. Hold the shovel in your main hand.
2. Dig dirt, sand, gravel, clay and snow.
3. Use the shovel on a grass block to make a path.
4. To repair the shovel, put it in an anvil with a bronze ingot.

## Numbers

| Property | Value |
|---|---|
| Durability | 300 uses (iron shovel: 250) |
| Mining level | Iron |
| Mining speed | 6.5 (iron shovel: 6.0) |
| Attack damage | 4.5 |
| Attack speed | 1.0 |
| Wear | 1 use for each block, 2 uses for each hit on a mob |
| Enchantability | 16 |
| Repair item | Bronze Ingot |
