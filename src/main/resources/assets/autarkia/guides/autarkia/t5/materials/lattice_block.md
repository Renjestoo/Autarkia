# Lattice Block

<ItemImage id="autarkia:lattice_block" scale="2" />

The lattice block is a building block of stone and lattice alloy. It resists explosions as well as obsidian.

## Get it

<RecipeFor id="autarkia:lattice_block" />

1. Put 1 <ItemLink id="autarkia:lattice_alloy_ingot" /> in the center of a crafting grid.
2. Put 8 stone around it.
3. Take the 8 lattice blocks.

## Use it

- Build walls that resist explosions.
- In Tier 6, 8 lattice blocks and 1 <ItemLink id="autarkia:aegis_plate" /> make 8
  <ItemLink id="autarkia:bastion_block" />.

## Numbers

| Property | Value |
|---|---|
| Output | 8 blocks per ingot |
| Hardness | 6 |
| Blast resistance | 1,200 |
| Mining tool | Diamond-level pickaxe |
