# Lattice Cluster

<ItemImage id="autarkia:lattice_cluster" scale="2" />

The lattice cluster is a violet crystal that grows in lattice geodes. It is the only source of
<ItemLink id="autarkia:lattice_shard" />, the base material of Tier 5.

## Get it

The cluster has no recipe.

1. Find a lattice geode (Y -58 to Y -24, about 1 geode in 40 chunks). See
   <ItemLink id="autarkia:lattice_geode_shell" />.
2. Clusters sit only on the charged shells of the geode.
3. More clusters grow on the free faces of charged shells over time.
4. Mine a cluster with a netherite-level pickaxe, for example a netherite pickaxe or the
   <ItemLink id="autarkia:vantite_excavator" />.

| Tool | Drop |
|---|---|
| Netherite-level pickaxe | 2 <ItemLink id="autarkia:lattice_shard" />, more with Fortune (ore bonus) |
| Netherite-level pickaxe with Silk Touch | The cluster itself |
| Weaker tool | Nothing |

## Use it

1. Mine clusters for shards.
2. Leave the charged shells in the geode, so that new clusters can grow.
3. With Silk Touch you can take a cluster home as a light block.

## Numbers

| Property | Value |
|---|---|
| Light level | 7 |
| Hardness | 1.5 |
| Shard drop | 2, Fortune adds more |
| Required tool level | Netherite |
| Pistons | Break it |
| Water | It can be waterlogged |

## Problems

- The cluster drops nothing: your pickaxe is below netherite level. Use a netherite-level pickaxe.
