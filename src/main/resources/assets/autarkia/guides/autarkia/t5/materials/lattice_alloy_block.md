# Block of Lattice Alloy

<ItemImage id="autarkia:lattice_alloy_block" scale="2" />

The block of lattice alloy stores 9 lattice alloy ingots. Some large machines use the whole block in their recipe.

## Get it

<RecipeFor id="autarkia:lattice_alloy_block" />

## Use it

1. Put 9 <ItemLink id="autarkia:lattice_alloy_ingot" /> in a crafting grid.
2. Place the block, or use it in a recipe.
3. Put the block back in a crafting grid to get the 9 ingots again.
