# Core Upgrade T5

<ItemImage id="autarkia:core_upgrade_t5" scale="2" />

The Core Upgrade T5 raises your Colony Core from tier 4 to tier 5. Tier 5 gives a larger domain, more workers, nanite
claims and the Replicator Walker.

## Get it

The <ItemLink id="autarkia:fabricator" /> makes it. Fabricator recipes do not show in this book, so the table gives
the recipe.

| Inputs | Machine | Time | Energy | Output |
|---|---|---|---|---|
| 1 <ItemLink id="autarkia:ai_core" />, 8 <ItemLink id="autarkia:lattice_alloy_ingot" />, 8 <ItemLink id="autarkia:nanite_paste" /> | <ItemLink id="autarkia:fabricator" /> | 200 ticks (10 s) | 160 FE/t | 1 Core Upgrade T5 |

## Use it

1. Make sure that your colony is active and at tier 4.
2. Hold the upgrade.
3. Use it on the Colony Core. You must be the owner or a trusted player.
4. The upgrade is used up. The Core plays its upgrade for 100 ticks (5 s).
5. Your colony is now tier 5.

## Numbers

| Colony value | Tier 5 |
|---|---|
| Domain half-size | 64 blocks |
| Worker cap | 26 |
| Active projects | 6 |
| Daily budget | 2,500 points |
| Domain beacons | 4, half-size 24 |
| Outposts | 6 at most, half-size 32, worker cap 8 each |
| Pattern library | 48 slots, capture up to 40 blocks per side |
| Stack size of the item | 16 |

## Problems

- "The Core must be active": the colony is not active. Make the Core active first.
- "Only the owner or trusted players can do this": ask the owner to use the upgrade, or to trust you.
- "The Core is already upgrading": wait until the current upgrade ends.
- "This upgrade needs a T4 Core (this one is T3)": the Core has the wrong tier. Use the upgrades in order.
