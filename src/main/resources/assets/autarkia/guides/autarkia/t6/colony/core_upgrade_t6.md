# Core Upgrade T6

<ItemImage id="autarkia:core_upgrade_t6" scale="2" />

The Core Upgrade T6 raises your Colony Core from tier 5 to tier 6, the last tier. The domain grows, the worker cap grows,
and the colony can use all tier 6 blocks.

## Get it

There is no crafting recipe. The <ItemLink id="autarkia:fabricator" /> makes it:

| Inputs | Machine | Time | FE | Output |
|---|---|---|---|---|
| 2 <ItemLink id="autarkia:aegis_plate" />, 2 <ItemLink id="autarkia:ai_core" />, 8 <ItemLink id="autarkia:lattice_crystal" /> | <ItemLink id="autarkia:fabricator" /> | 200 ticks | 160 FE/t, 32,000 FE in total | 1 Core Upgrade T6 |

You get the aegis plates from the <ItemLink id="autarkia:matter_compiler" />. Build the compiler while your colony is at
tier 5.

## Use it

1. Make sure that your colony is active and at tier 5.
2. Hold the upgrade. Use it on the Colony Core. You must be the owner or a trusted player.
3. The upgrade is used up. The Core plays its upgrade for 100 ticks.
4. Then the colony is tier 6.

## Numbers

| Tier 6 value | Value |
|---|---|
| Domain half-size | 96 blocks |
| Worker cap | 32 |
| Active projects | 8 |
| Daily budget | 6,000 points |
| Domain beacons | 6, half-size 24 |
| Outposts | 6, square 65 x 65 (half-size 32) |
| Worker cap of an outpost core | 10 |
| Pattern library | 128 Patterns, capture up to 48 blocks per axis |

## Problems

- "This upgrade needs a T5 Core (this one is TN)": the Core is not tier 5. Use the upgrades in order.
- "The Core must be active": the colony is not active.
- "The Core is already upgrading": wait for the end of the running upgrade.
- "Only the owner or trusted players can do this": ask the owner to trust you.
